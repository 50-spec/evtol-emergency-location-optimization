# bishe

项目用于托管代码。

## 说明

这个仓库用于托管项目代码。把你的代码推到 main 分支即可开始使用。

## 快速开始

1. 在本地初始化并推送：

```
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/50-spec/bishe.git
git push -u origin main
```

2. 或者从远程克隆：

```
git clone https://github.com/50-spec/bishe.git
```

## 目录结构

建议把源码放到 `src/` 或按语言的惯例组织目录。
